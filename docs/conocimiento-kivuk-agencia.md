# Base de conocimiento — Kivuk Agencia

Documentos curados para cargar en la pestaña **Conocimiento** del panel
(`/dashboard/<clientId>/conocimiento`), o de una vez:

```
node scripts/cargar-conocimiento.js docs/conocimiento-kivuk-agencia.md "Kivuk Agencia" --aplicar
```

Fuente: `docs/explicacion_servicios_agencia_kivuk.md`, escrito por el titular el
**04/09/2026**, más el estado real de la plataforma a esa fecha. Lo que no está
construido **no está escrito como disponible**: está como «en desarrollo», y eso
es deliberado. Este bot le habla a compradores potenciales; un servicio
prometido aquí es un servicio que habrá que entregar en la primera reunión.

Lo que no se ha podido confirmar está al final, en «Pendiente de confirmar», y
**no se carga** hasta que el titular lo confirme.

Se sigue la regla aprendida con Cestería: **cada documento empieza por dos o
tres formulaciones coloquiales de lo que resuelve**, porque el buscador no
recupera el documento que contiene la respuesta, sino el que se parece a la
pregunta.

# Pendiente de confirmar

Nada de esto se carga hasta que el titular lo confirme. Está aquí porque el bot
