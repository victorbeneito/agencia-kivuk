# Batería de preguntas reales para el bot de Cestería Aparici.
# Se lanza con:
#   node scripts/probar-conocimiento.js "Cesteria Aparici" --bateria docs/preguntas-cesteria-aparici.txt
#
# Cada línea es una pregunta tal y como la escribiría un cliente por WhatsApp:
# sin tildes, con faltas y con prisa. Las últimas son las importantes: preguntas
# cuya respuesta NO está en la base de conocimiento. Ahí el bot tiene que decir
# que no lo sabe, y eso se comprueba viendo que no recupera nada relevante.
