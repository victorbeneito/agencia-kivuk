# Batería de preguntas reales para el bot de Peluquería Mechas (demo).
# Se lanza con:
#   node scripts/probar-conocimiento.js "Peluqueria Mechas" --bateria docs/preguntas-peluqueria-mechas.txt
#
# Cada línea es una pregunta tal y como la escribiría una clienta por WhatsApp:
# sin tildes, con faltas y con prisa. Las últimas son las importantes: preguntas
# cuya respuesta NO está en la base de conocimiento. Ahí el bot tiene que decir
# que no lo sabe, y eso se comprueba viendo que no recupera nada relevante.
